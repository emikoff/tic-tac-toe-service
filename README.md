# Крестики-нолики — Python Bootcamp T03

Учебный веб-проект на Flask: пользователь играет против компьютера, который
выбирает ходы алгоритмом minimax. Реализация выполнена по заданию T03 и
разделена на слои `web`, `domain`, `datasource` и `di`.

## Возможности

- создание нескольких независимых партий;
- проверка присланного игрового поля и хода пользователя;
- ответ компьютера алгоритмом minimax;
- определение победы, ничьей и продолжающейся игры;
- браузерный интерфейс и JSON API;
- хранение партий в потокобезопасном словаре в памяти процесса.

Состояние партий хранится только в памяти и сбрасывается после перезапуска
сервера. Проект предназначен для локального запуска и демонстрации учебного
задания, а не для production-развёртывания.

## Запуск

Нужен Python 3.10 или новее. Команды запускаются из каталога `src/`:

```bash
cd src
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Открой в браузере <http://127.0.0.1:5000/>. Flask development server запускается
в режиме отладки, поэтому его следует использовать только локально.

## JSON API

Создать партию:

```bash
curl -X POST http://127.0.0.1:5000/game
```

Сделать ход пользователя, передав поле после его хода:

```bash
curl -X POST http://127.0.0.1:5000/game/UUID \
  -H 'Content-Type: application/json' \
  -d '{"matrix":[[1,0,0],[0,0,0],[0,0,0]]}'
```

Значения клеток: `0` — пустая, `1` — пользователь, `2` — компьютер.
Ответ содержит UUID партии, обновлённое поле и статус игры. При некорректном
запросе API возвращает описание ошибки.

## Проверки

В `src/tests/` находятся тесты доменной логики, хранилища, HTTP-маршрутов и
веб-интерфейса. Запусти их из каталога `src/`:

```bash
python -m pytest
```

Зависимости приложения и тестов перечислены в `src/requirements.txt`.

## Структура

```text
src/
├── app.py
├── domain/       игровые модели, правила и minimax

├── web/          Flask-маршруты, модели, мапперы и UI
├── di/           сборка зависимостей
```

## Соответствие заданию T03

| Требование задания | Реализация |
|---|---|
| Разделить приложение на `web`, `domain`, `datasource`, `di` | Каталоги в `src/` |
| Описать поле, игру и интерфейс сервиса | `src/domain/` |
| Проверять ход и окончание игры, выбирать ход minimax | `src/domain/service/` |
| Хранить партии и преобразовывать модели между слоями | `src/datasource/` |
| Реализовать Flask API, ошибки и несколько партий | `src/web/route/game_routes.py` |
| Связать хранилище, репозиторий и сервис через контейнер | `src/di/container.py` |
