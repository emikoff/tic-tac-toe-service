# Крестики-нолики — Python Bootcamp T03 / T04B

Учебное веб-приложение на Flask. В версии T03 можно играть против компьютера
с алгоритмом minimax. В T04B добавлены PostgreSQL, регистрация и авторизация,
а также партии между двумя пользователями.

## Версии

| Версия | Содержание |
|---|---|
| `v0.1.0` | T03: игра против компьютера, minimax, хранение партий в памяти процесса |
| `main` | T04B: PostgreSQL, пользователи, авторизация, игра между двумя пользователями |

Для отклика на T03 используйте ссылку на тег `v0.1.0`. Ссылка на T04B будет
доступна после проверки и выпуска тега `v1.0.0`.

## Возможности T04B

- регистрация и вход с проверкой учётных данных через Basic Authentication;
- хеширование паролей и защита игровых и пользовательских API;
- создание игры против компьютера или другого пользователя;
- список открытых игр, присоединение к игре и получение её состояния;
- смена очереди, проверка участника и завершение игры победой или ничьей;
- хранение игр и пользователей в PostgreSQL;
- браузерный интерфейс и JSON API.

## Запуск

Нужны Python 3.10+, Docker Compose и PostgreSQL. Команды запускайте из корня
репозитория:

```bash
cp src/.env.example src/.env
docker compose --env-file src/.env -f src/docker-compose.yaml up -d
cd src
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Откройте <http://127.0.0.1:5000/>. Для локального входа сначала зарегистрируйте
пользователя через интерфейс. `.env.example` содержит учебные локальные
параметры подключения; замените пароль, если запускаете приложение вне
изолированной среды.

Остановка PostgreSQL из корня репозитория:

```bash
docker compose --env-file src/.env -f src/docker-compose.yaml down
```

## API T04B

Маршруты требуют авторизацию, кроме регистрации и входа.

| Метод и путь | Назначение |
|---|---|
| `POST /auth/signup` | Регистрация |
| `POST /auth/login` | Вход с Basic Authentication |
| `POST /game` | Создание игры; JSON `{"opponent_type":"COMPUTER"}` или `{"opponent_type":"USER"}` |
| `GET /game` | Список доступных игр |
| `POST /game/<uuid>/join` | Присоединение ко второй пользовательской игре |
| `GET /game/<uuid>` | Получение состояния игры |
| `POST /game/<uuid>` | Передача хода и нового поля |
| `GET /user/<uuid>` | Получение пользователя по UUID |

Учебный API принимает логин и пароль в Basic Authentication. Не используйте
его без HTTPS или с настоящими паролями в публичной сети.

## Проверки

Тесты находятся в `src/tests/`. Для их запуска нужна база, указанная в
`TEST_DATABASE_URL` файла `src/.env`:

```bash
cd src
source .venv/bin/activate
pytest
```

сценарий двух пользователей — регистрация, создание игры, присоединение и
ходы по очереди. При изменении кода эти проверки следует повторить.
