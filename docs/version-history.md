репозитории и доступны по тегам.

## Изменения T04B

- добавлены SQLAlchemy-модели, репозитории и мапперы для игр и пользователей;
- добавлена конфигурация PostgreSQL через `.env` и Docker Compose;
- добавлены регистрация, Basic Authentication и хеширование паролей;
- добавлены игровые сценарии для двух пользователей;
- добавлены тесты приложения и HTTP API.

Для версии `v1.0.0` тесты прошли: **176 passed**. Браузерная проверка включала
регистрацию двух пользователей, создание и поиск открытой игры, присоединение
и последовательные ходы.
