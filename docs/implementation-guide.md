# Технические заметки T03

Этот документ описывает версию T03 по тегу `v0.1.0`. Ветка `main` содержит
более позднюю реализацию T04B.

[← README](../README.md)

## Состав T03

T03 — веб-игра «Крестики-нолики» на Flask. Реализация разделена на слои
`web`, `domain`, `datasource` и `di`. Компьютер выбирает ход алгоритмом minimax,
а состояние игры хранится в памяти процесса. Доступны браузерный интерфейс и
JSON API.

## Запуск

Из каталога `src/` создай виртуальное окружение, установи зависимости и запусти
сервер:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

## Проверка

В активированном окружении выполни:

```bash
pytest
```

Браузерный сценарий: открыть игру, сделать ход, дождаться ответа компьютера и
начать новую партию.

## Ограничение хранения

Состояния T03 находятся в памяти и исчезают при перезапуске приложения.
Настройки PostgreSQL и пользовательские сценарии относятся к версии T04B,
которая находится в `main`.
